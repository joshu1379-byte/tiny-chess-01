A 4 KB Python chess engine for make.fun's tiny-chess-01 bounty: 0x88 alpha-beta
search with quiescence, a transposition table, null-move pruning, killer moves
and formula piece-square tables, under a fixed 50,000-node budget per move.
It plays the house gauntlet through the env at MAKEFUN_ENV_URL.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
